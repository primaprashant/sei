# Task 21 Captures

Generated production `View` text with the 25 pinned upstream skills, three agents,
and initially absent destinations. Paths are replaced with `<FIXTURE>` **before**
layout; these are reproducible model snapshots, not pixel screenshots or terminal
emulator reconstructions. Trailing padding is omitted. PTY geometry, full-target,
failure, and timing evidence is described in [the report](../prototype.md).

The `*-pty.txt` files separately preserve actual Linux PTY startup output with
ANSI/control bytes quoted and temporary paths sanitized, including truncated
paths. They are output transcripts, not reconstructed screens. `linux-timings.txt`
is the recorded timing run; regenerating captures produces a new timing sample.
